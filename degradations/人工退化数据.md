## 2. 实现的退化类型

已实现 5 类退化：

```text
1. lowlight：低光照退化
2. blur：运动模糊退化
3. jpeg：JPEG 压缩退化
4. haze：雾霾退化
5. mixed：混合退化
```

其中 `mixed` 会从低光、模糊、JPEG、雾霾中随机选择 2 到 3 种顺序叠加，用于模拟更真实的复杂退化场景。

## 3. 各文件作用

`lowlight.py`：
实现低光照合成，通过 gamma 变暗、亮度衰减、轻微色偏和噪声生成低光图像。

`motion_blur.py`：
实现运动模糊合成，构造指定长度和角度的运动模糊核，并使用频域卷积生成模糊图像。

`jpeg.py`：
实现 JPEG 压缩退化，将图像经过低质量 JPEG 编码和解码，生成块效应和压缩伪影。

`haze.py`：
实现基于大气散射模型的雾霾合成：

```text
I(x) = J(x)t(x) + A(1 - t(x))
```

其中深度图使用平滑伪深度近似生成，不需要额外深度数据。

`generate_dataset.py`：
统一的数据集生成入口，负责读取 DIV2K、裁剪 patch、生成五类退化图像、保存 GT/LQ 和记录元数据。

`README.md`：
记录脚本使用方式、输出目录结构和依赖说明。

```text
numpy

```

没有强制依赖 OpenCV，后续复现和部署更简单。

安装方式：

```bash
pip install numpy pillow
```

## 7. 数据异常处理

生成时发现：

```text
data/DIV2K_train_HR/0001.png
```

该文件无法被 Pillow 正常识别，但同目录下存在可用的：

```text
data/DIV2K_train_HR/0001.jpeg
```

因此脚本已加入不可读图像跳过逻辑，并且会在同名文件重复时保留第一张可读图像，避免整个数据生成流程被单个坏图打断。
