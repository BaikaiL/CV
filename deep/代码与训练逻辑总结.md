# 深度学习方法版代码与训练逻辑总结

本文档说明 `deep/` 目录中 Prompt-LoRA Restormer 的代码结构、模型前向逻辑、训练流程、验证流程和推理流程，方便后续写课程报告、答辩讲解和做消融实验。

## 1. 整体目标

深度学习方法版的目标是训练一个统一的图像复原模型，用同一套 DIV2K 人工退化数据处理多种退化类型：

```text
低质量图像 LQ
  ↓
Prompt-LoRA Restormer
  ↓
复原图像 output
  ↓
与 GT 计算 Loss / PSNR / SSIM
```

模型需要同时支持：

```text
lowlight：低光照
blur：运动模糊
jpeg：JPEG 压缩噪声
haze：雾霾
mixed：混合退化
```

因此代码中设计了两个关键模块：

```text
1. Degradation Prompt Module：为不同退化提供可学习提示
2. LoRA Attention：用低秩适配器增强 Q/V 注意力投影
```

## 3. 数据读取逻辑

数据读取在 `dataset.py` 中实现，核心类是：

```python
DIV2KRestorationDataset
```

它读取 `data/degradation_metadata.csv`，根据 metadata 中记录的路径自动配对：

```text
lq：人工退化图像
gt：原始清晰图像 patch
degradation：退化类型
params：退化参数
```

每个样本返回一个字典：

```python
{
    "lq": Tensor[C, H, W],
    "gt": Tensor[C, H, W],
    "degradation": LongTensor,
    "mix_weights": Tensor[4],
    "name": str,
    "degradation_name": str,
}
```

其中：

```text
lq：输入模型的低质量图像，范围为 [0, 1]
gt：监督训练使用的清晰图像，范围为 [0, 1]
degradation：退化类型的数字标签
mix_weights：混合退化时 4 种基础退化 prompt 的权重
```

退化类型映射为：

```text
lowlight → 0
blur     → 1
jpeg     → 2
haze     → 3
mixed    → 4
```

### 3.1 普通退化的 Prompt 权重

如果样本是单一退化，例如 `jpeg`，那么 `mix_weights` 是 one-hot 风格：

```text
lowlight blur jpeg haze
[0,      0,   1,   0]
```

### 3.2 混合退化的 Prompt 权重

如果样本是 `mixed`，代码会从 `params` 字段中解析实际参与混合的退化类型。

例如：

```text
blur+jpeg|blur[length=27;angle=153.78]|jpeg[quality=24]
```

会得到：

```text
lowlight blur jpeg haze
[0,      0.5, 0.5, 0]
```

这样模型在处理 mixed 图像时，不是使用一个固定的 mixed prompt，而是使用多个基础 prompt 的加权组合，更符合项目方案中：

```text
P_mix = α1P_lowlight + α2P_blur + α3P_jpeg + α4P_haze
```

## 4. 模型总体结构

主模型在 `model.py` 中，类名是：

```python
PromptLoRARestormer
```

整体结构为轻量 Encoder-Decoder：

```text
LQ image
  ↓
Patch Embedding
  ↓
Encoder Stage 1
  ↓ downsample
Encoder Stage 2
  ↓ downsample
Bottleneck Transformer Blocks
  ↓
Degradation Prompt Module
  ↓
Decoder Stage 2
  ↓ upsample
Decoder Stage 1
  ↓
Refine Blocks
  ↓
Output Conv
  ↓
Residual Add + Clamp
```

代码中的主要路径是：

```python
x1 = encoder1(patch_embed(x))
x2 = encoder2(down1(x1))
x3 = bottleneck(down2(x2))
x3 = prompt(x3, degradation, mix_weights)
x  = decoder with skip connections
out = clamp(input + output_conv(x), 0, 1)
```

这里使用了残差学习：

```text
复原结果 = 输入退化图像 + 网络预测的残差
```

这样做的好处是模型不需要从零生成整张图，而是重点学习：

```text
去噪、去雾、提亮、锐化、去模糊等修正量
```

训练更稳定，也更适合图像复原任务。

## 5. Transformer Block 逻辑

每个 `TransformerBlock` 包含两部分：

```text
1. LayerNorm2d + MDTA Attention
2. LayerNorm2d + Gated Feed Forward
```

前向逻辑：

```python
x = x + attention(norm1(x))
x = x + ffn(norm2(x))
```

这是一种标准残差结构：

```text
输入特征
  ↓
归一化
  ↓
注意力 / 前馈网络
  ↓
与原特征相加
```

残差结构可以缓解深层网络训练中的梯度问题，也能保留低层图像细节。

## 6. MDTA Attention 逻辑

代码中的 `MDTAAttention` 是 Restormer 风格的通道注意力。

普通全局自注意力如果直接在 256×256 图像上计算，复杂度非常高：

```text
token 数 = 256 × 256 = 65536
attention 矩阵会非常大
```

所以这里采用 Restormer 的思路，不在空间 token 之间做巨大 attention，而是在通道维度做注意力，计算更轻量。

核心步骤：

```text
输入特征 x
  ↓
1×1 Conv 生成 QKV
  ↓
Depthwise Conv 引入局部空间信息
  ↓
Q、K 归一化
  ↓
计算通道注意力
  ↓
与 V 相乘
  ↓
1×1 Conv 输出
```

代码中对应：

```python
q, k, v = dwconv(qkv(x)).chunk(3, dim=1)
q = normalize(q)
k = normalize(k)
attn = softmax(q @ k.T * temperature)
out = attn @ v
```

这里的 `temperature` 是可学习参数，用来调节 attention 分布的锐利程度。

## 7. LoRA 模块逻辑

LoRA 在 `lora.py` 中实现，核心类是：

```python
LoRAConv2d
```

原理来自：

```text
W' = W + BA
```

在代码里对应两个 1×1 卷积：

```text
down：channels → rank
up：rank → channels
```

即：

```python
lora(x) = up(down(x)) * scale
```

在 `MDTAAttention` 中，LoRA 加在 Q 和 V 分支：

```python
q = q + q_lora(x)
v = v + v_lora(x)
```

这样做的含义是：

```text
主干 attention 仍然保留原有表达能力
LoRA 只学习一个低秩增量
用很少参数适配不同退化复原任务
```

如果训练时加上：

```powershell
--freeze-backbone
```

代码会调用：

```python
mark_only_lora_prompt_trainable(model)
```

它会冻结大部分主干参数，只训练名称中包含以下关键字的参数：

```text
lora
prompt
output
refine
```

这正好对应课程方案中“冻结主干，只训练 LoRA + Prompt + 输出层”的设计。

## 8. Prompt Module 逻辑

Prompt 模块在 `prompt_module.py` 中实现：

```python
DegradationPromptModule
```

它为 4 种基础退化各维护一个可学习向量：

```text
P_lowlight
P_blur
P_jpeg
P_haze
```

这些 prompt 的形状是：

```text
[4, channels]
```

处理单一退化时，直接取对应 prompt：

```text
degradation = jpeg
prompt = P_jpeg
```

处理混合退化时，使用 `mix_weights` 对四个 prompt 加权：

```text
prompt = α1P_lowlight + α2P_blur + α3P_jpeg + α4P_haze
```

得到 prompt 后，会经过一个小 MLP：

```python
Linear → GELU → Linear
```

然后 reshape 成：

```text
[B, C, 1, 1]
```

最后注入 bottleneck 特征：

```python
features = features + prompt
```

之所以放在 bottleneck，是因为 bottleneck 处语义更集中、空间尺寸更小，适合加入退化类型条件信息，同时计算开销也比较小。

`build_model()` 支持四种模式：

```text
baseline     = 无 Prompt，无 LoRA
prompt       = 有 Prompt，无 LoRA
lora         = 无 Prompt，有 LoRA
prompt_lora  = 有 Prompt，有 LoRA
```

这四个模式正好用于消融实验：

```powershell
.\.venv\Scripts\python.exe -m deep.train --variant baseline
.\.venv\Scripts\python.exe -m deep.train --variant prompt
.\.venv\Scripts\python.exe -m deep.train --variant lora
.\.venv\Scripts\python.exe -m deep.train --variant prompt_lora
```

实验报告中可以比较：

```text

LoRA 是否用更少训练参数获得接近或更好的效果
Prompt + LoRA 是否优于单独模块
```

## 10. 损失函数逻辑

损失函数在 `losses.py` 中：

```python
RestorationLoss
```

总损失为：

```text
Loss = L1 + 0.1 × SSIMLoss + 0.05 × EdgeLoss
```

### 10.1 L1 Loss

```text
L1 = |output - gt|
```

作用：

```text
保证像素级复原准确
使颜色、亮度、整体内容接近 GT
```

### 10.2 SSIM Loss

```text
SSIMLoss = 1 - SSIM(output, gt)
```

作用：

```text
约束图像结构相似性
减少只追求像素误差造成的结构失真
```

### 10.3 Edge Loss

EdgeLoss 使用 Sobel 算子提取边缘：

```text
EdgeLoss = |Sobel(output) - Sobel(gt)|
```

作用：

```text
强化边缘、纹理和轮廓
对去模糊、JPEG 细节恢复特别有帮助
```

## 11. 训练脚本逻辑

训练入口是：

```powershell
.\.venv\Scripts\python.exe -m deep.train
```

核心流程在 `train.py` 中：

```text
1. 解析命令行参数
2. 选择 cuda / cpu
3. 构建训练集和验证集
4. 构建模型
5. 可选冻结主干
6. 构建 loss、optimizer、AMP scaler
7. 进入 epoch 训练循环
8. 每个 epoch 后验证 PSNR / SSIM
9. 保存 last.pth 和 best.pth
```

### 11.1 参数解析

常用参数：

```text
--variant：选择 baseline / prompt / lora / prompt_lora
--epochs：训练轮数
--batch-size：batch 大小
--lr：学习率
--dim：模型基础通道数
--lora-rank：LoRA 低秩维度
--degradations：指定训练哪些退化类型
--freeze-backbone：只训练 LoRA、Prompt、输出层
--amp：开启 CUDA 混合精度
```

### 11.2 DataLoader

训练集：

```python
shuffle=True
drop_last=True
```

含义：

```text
每轮随机打乱样本
丢弃最后不足 batch 的样本，保证 batch 尺寸稳定
```

验证集：

```python
batch_size=1
shuffle=False
```

含义：

```text
逐张验证，指标更直观
固定顺序，便于复现实验结果
```

### 11.3 模型与训练参数

模型构造：

```python
model = build_model(args.variant, dim=args.dim, lora_rank=args.lora_rank)
```

如果开启冻结主干：

```python
mark_only_lora_prompt_trainable(model)
```

训练脚本会打印：

```text
trainable params / total params
```

这个信息可以直接用于实验表格中的“参数量”或“可训练参数量”对比。

### 11.4 优化器

使用：

```python
AdamW
```

默认学习率：

```text
2e-4
```

权重衰减：

```text
1e-4
```

AdamW 适合 Transformer 类模型训练，权重衰减可以抑制过拟合。

### 11.5 AMP 混合精度

如果使用：

```powershell
--amp
```

训练会启用：

```python
torch.amp.autocast
torch.amp.GradScaler
```

作用：

```text
减少显存占用
提升训练速度
在 RTX 4060 Laptop GPU 上更适合跑大 batch 或更大 dim
```

### 11.6 单个 batch 的训练步骤

每个 batch 的逻辑：

```text
1. batch 移动到 GPU
2. optimizer 清零梯度
3. 模型前向：output = model(lq, degradation, mix_weights)
4. 计算 loss
5. 反向传播
6. 梯度裁剪
7. optimizer 更新参数
8. 写入 TensorBoard
```

对应代码逻辑：

```python
output = model(batch["lq"], batch["degradation"], batch["mix_weights"])
loss, parts = criterion(output, batch["gt"])
loss.backward()
clip_grad_norm_(model.parameters(), 1.0)
optimizer.step()
```

其中梯度裁剪：

```text
clip_grad_norm = 1.0
```

作用是防止 Transformer 训练早期梯度过大导致不稳定。



## 21. 课程项目省时训练逻辑

本项目是课程项目，目标是完成一个结构完整、实验可展示、指标可对比的系统，而不是追求最优复原效果。因此 `train.py` 已经加入“课程项目模式”，默认减少训练时间。

### 21.1 为什么原训练很慢

人工退化数据中训练集规模大约是：

```text
6400 个 GT patch × 5 类退化 = 32000 个 LQ 样本
```

如果使用：

```powershell
--batch-size 4
```

每个 epoch 需要：

```text
32000 / 4 = 8000 step
```

再训练 50 个 epoch，就是：

```text
8000 × 50 = 400000 step
```

这对课程项目明显过重，也不利于快速完成消融实验。

### 21.2 当前默认省时策略

现在训练脚本默认参数调整为：

```text
epochs = 12
dim = 24
course_train_samples = 1200
course_valid_samples = 40
val_interval = 2
early_stop_patience = 4
```

含义如下：

```text
每轮只随机取 1200 个训练样本
每次验证只随机取 40 个验证样本
每 2 个 epoch 验证一次
PSNR 连续 4 次验证没有明显提升就提前停止
模型宽度从 32 降到 24，减少参数量和显存占用
```

这样每个 epoch 的训练步数变为：

```text
1200 / 4 = 300 step
```

比原来的 8000 step/epoch 少很多，更适合在课程项目中快速得到结果。

### 21.3 原命令也会变快

即使继续使用：

```powershell
.\.venv\Scripts\python.exe -m deep.train --variant prompt_lora --epochs 50 --batch-size 4 --num-workers 4 --amp
```

脚本仍然会使用课程项目模式：

```text
每轮 1200 个训练样本
每次 40 个验证样本
每 2 轮验证一次
自动早停
```

所以不会再每轮完整扫描 32000 个样本。

### 21.5 完整训练开关

如果后续希望追求更高指标，可以加：

```powershell
--full-training
```

例如：

```powershell
.\.venv\Scripts\python.exe -m deep.train `
  --variant prompt_lora `
  --epochs 50 `
  --batch-size 4 `
  --num-workers 4 `
  --amp `
  --full-training
```

开启后会使用全部训练和验证数据，并每个 epoch 都验证，耗时会显著增加。
